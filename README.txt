# Portfólio Dérik Lima

## Como abrir no Visual Studio Code
1. Extraia esta pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Para visualizar, clique com o botão direito em `index.html` e use o Live Server, se tiver instalado.

## Como colocar sua foto
No site existe o botão **Adicionar fotos**. Ele permite escolher várias fotos do celular/computador e mostra as fotos na galeria enquanto a página está aberta.

Para deixar uma foto fixa no perfil, coloque a imagem dentro da pasta `img` e substitua o bloco `photo-placeholder` no `index.html` por:
`<img class="profile-photo" src="img/sua-foto.jpg" alt="Dérik Lima">`

O site foi feito com HTML, CSS e um pequeno JavaScript apenas para a galeria de fotos.
